# 3D-концепция «Срез»

Статус: прототип в песочнице (`/lab`). Ничего не выкачено, в `main` не мержено.
Дата: 2026-11-04. Код: `src/lab/*`, `src/pages/lab/*`, `src/layouts/LabLayout.astro`.

## Как посмотреть

```
npm install
npm run dev
```

- http://localhost:4321/lab — оглавление песочницы
- http://localhost:4321/lab/srez — главная-прототип

## Идея в одном абзаце

Главная — спил сосны. Одно кольцо — один год, от сердцевины (2020) до коры (текущий год). Ширина кольца — сколько проектов шло в тот год. Проекты — сучки: в настоящем спиле ветка видна именно так, тёмной полосой от года, когда выросла, наружу. Чем дольше шёл проект, тем длиннее сучок. Gabarshop тянется от сердцевины до коры: «never fully left». Справа клиентская работа, слева своё. Спил связан со списком проектов в HTML: навёл на сучок — подсветился проект, навёл на проект — загорелся сучок, прокрутил до года — загорелось кольцо.

**Функция 3D:** это не украшение, а оглавление и диаграмма одновременно. За 10 секунд видно: сколько лет в профессии, как росла загрузка, что клиентское, что своё, что длилось годами. Это radial timeline, просто нарисованный материалом, который знаком всем.

**Ответ на вопрос про число колец в логотипе:** логотип остаётся с тремя кольцами (проверено на 16 px, см. ниже). Настоящее число лет показывает спил. Он строится из данных при сборке и сам добавляет кольцо каждый январь. Логотип — росток, спил — ствол.

## Почему не шаблон (сверка со скиллом frontend-design от Anthropic)

Скилл: `anthropics/skills/skills/frontend-design/SKILL.md`. В нём список примет «сгенерированного» дизайна. Сверка:

| Примета из скилла | У нас |
|---|---|
| Кремовый фон + антиква + терракота | Фон — холодный туман соснового бора `#DCE1DB`. Шрифт без засечек. Терракоты нет: тёплые цвета только в самом дереве |
| Почти чёрный фон + кислотный акцент | Светлая тема. Акцент — цвет живицы, только для подсветки в 3D и полоски у активного проекта |
| Газетная вёрстка, волосяные линии, без скруглений | Нет колонок-газеты. Разделители только между годами: они несут смысл (граница года) |
| Одинаковые карточки с тенью | Карточек нет вообще. Проекты — строки списка |
| КАПС-надписи над заголовками, мета через «·», моноширинный для меток, «→» в ссылках | Ничего из этого. Мета — две строки обычного текста |
| Нумерация 01/02/03 без последовательности | Годы — настоящая последовательность, поэтому крупные цифры уместны |
| Fade-up у каждой секции | Одно движение без участия человека — рост спила при загрузке. Всё остальное отвечает на действие |

Где честно есть риск шаблона: «большая цифра года» близка к приёму «big number with small label». Оставил, потому что это заголовок раздела хронологии, а не украшение. Если будет читаться как шаблон — уменьшить до 40 px.

### Токены

- Цвет: туман `#DCE1DB`, туман-2 `#CDD4CC`, хвоя (текст) `#1F2B24`, хвоя-2 `#4A574F`, мох `#44603E` (наследник текущего акцента `#5C7A54`), живица `#E3A12F` (только подсветка).
- Шрифт: Geologica (variable, есть кириллица, самохостинг через `@fontsource-variable/geologica`). Одна гарнитура на всё, характер — через вес: 220 для годов, 380 для заголовка, 500 для названий проектов.
- Сетка: слева липкая сцена (55%), справа список. Выравнивание по левому краю. На телефоне сцена сверху на половину экрана, список под ней.

## Что сделано технически

- `src/lab/data.ts` — проекты (тексты скопированы с текущей главной без правок), расчёт колец и сучков. «Сейчас» берётся из даты сборки: текущее кольцо дорастает в течение года (в ноябре — 84%).
- `src/lab/log.ts` — спил: геометрия с неровным контуром ствола, процедурные шейдеры поверх `MeshStandardMaterial`. Заболонь и ядро, поздняя древесина, сердцевина, сердцевинные лучи, следы пилы, трещины усушки (они же граница половин), сучки, медная кора сосны обыкновенной. Ни одной текстуры, всё считается из данных.
- `src/lab/svgCut.ts` — тот же спил в SVG. Виден сразу при загрузке (до 3D), без JS и без WebGL. Сайт полный без 3D.
- `src/lab/cutScene.ts` — сцена, связь со списком, подписи годов поверх 3D (HTML, спроецированный из 3D-координат), подсветка половин.
- Рендер по требованию: кадр рисуется только когда что-то меняется. В покое GPU не работает, батарея не садится.
- `prefers-reduced-motion`: без анимации роста и без наклона за курсором.
- Тач: первое касание сучка показывает проект, второе открывает.

Вес: three.js — основная часть бандла. Замерить после `npm run build` (см. ниже).

## Логотип: 4 варианта (`/lab/logo`)

1. **Выжженный на спиле** — знак как клеймо на сосновом спиле. Курсор = скользящий свет.
2. **Живица** — знак отлит из янтарной смолы, внутри застряла хвоинка. Самый эффектный и самый тяжёлый.
3. **Рост** — кольца откладываются по одному. Замена Lottie-загрузки. Честно: объём тут почти ничего не даёт.
4. **Разбор на слои** — прокрутка разводит сердцевину и кольца. Для блока «Обо мне» про Сосновку.

Моё мнение: в продакшн нужен максимум один. Лучше всего — финальный кадр «Среза», где спил при прокрутке до контактов поворачивается сверху и превращается в знак (вариант 1 как переход). Живица — для 404 или «Обо мне», если хочется вау.

### Сколько колец

Проверено рендером на 16/32/64/160 px при 1x и 2x. На обычном экране при 16 px: 3 кольца чисто, 4 на грани, 5+ рябь. На ретине держатся 4–5. Решение: оставить 3.

## Что не проверено

- **FPS на реальном телефоне.** Здесь только программный рендер (SwiftShader), его цифры ничего не значат. Открыть `/lab/srez?fps` на телефоне и записать: модель, FPS при загрузке, FPS при наведении/прокрутке. Цель — 50+ во время анимации. В покое рендер стоит.
- Safari iOS: `fwidth`/`dFdx` в шейдере и `svh` в CSS — должны работать, но не проверено.
- Тексты: подпись-легенда «как читать спил» и строки вроде «One project running, no new starts» — черновые, написал для прототипа. Переписать вместе с остальными текстами.
